# 页面细节与结构优化计划

## 目标
响应用户对于页面细节的优化需求，主要包含以下三个方面：
1. **导航栏毛玻璃特效强化**：让顶部导航栏具有更通透、更明显的物理折射/毛玻璃感。
2. **Display 系列数据的正确展示**：修复用户反馈的“只能看到一个 Display 链接”的问题，确保展示页 01, 02, 03 都能独立展示。
3. **工具卡片的分类展示**：重构“工具与创作”区域，引入分类（Tabs 或分类区块），避免链接过多时全部挤在一起，提升扩展性和查找效率。

## 实施步骤

### 1. 强化顶部导航栏的毛玻璃 (Glassmorphism) 效果
- 在 `src/pages/Home.tsx` 中定位导航栏 `<nav>` 元素。
- 修改 Tailwind 类名：
  - 降低背景透明度（如从 `bg-[#FAFAFA]/80` 改为 `bg-white/40` 或更低）。
  - 增加背景模糊度（如 `backdrop-blur-xl` 甚至 `backdrop-blur-2xl`）。
  - 增加一个微弱的白色/半透明边框（如 `border-b border-white/40`）和内部阴影，模拟真实玻璃的边缘反光，使得底层动态背景能够透出并被折射。

### 2. 修复并确保 Display 系列正确展示
- 在之前的代码中，虽然我们在 `initialApps` 中添加了 `display01`, `display02`, `display03`，但由于用户本地浏览器可能已经缓存了旧的 `localStorage` 数据（其中只有 `display` 一个项目），导致前台没有更新。
- **解决方案**：在 `src/pages/Home.tsx` 挂载时（`useEffect`），或者通过某种版本控制机制，强制将新的 `initialApps` 与本地缓存进行合并，或者提供一个显式的提示让用户知道如何重置缓存，以确保能看到所有的 display 链接卡片。最简单稳妥的做法是在 `store/useStore.ts` 中升级 `persist` 的版本，或者在检测到缺失特定 key 时自动补全。

### 3. 重构“工具与创作”区域的分类展示
- 在 `src/pages/Home.tsx` 的“工具与创作”板块中引入分类逻辑。
- **分类策略**：
  - 提取所有 AppItem 的 `category` 字段，生成唯一的分类列表（如：“全部”, “智能教学辅助”, “教务与管理”, “综合展示”）。
- **UI 交互**：
  - 在卡片列表上方增加一行 **分类标签切换器 (Tabs)**。
  - 用户点击不同的标签时，使用 `framer-motion` 的 `AnimatePresence` 对下方卡片进行平滑的过滤和重新排列（Layout Animation）。
  - 这样即使未来挂载了几十个链接，用户也能通过分类标签快速定位，页面也不会显得杂乱无章。

## 预期效果
- 页面滚动时，顶部的导航栏像一块真实的磨砂玻璃，底部的图片颜色能柔和地透上来。
- “工具与创作”区域变得井井有条，用户可以通过点击标签来筛选不同类型的工具（教学辅助、教务管理、展示页）。
- 所有 3 个 Display 系列的链接都会独立显示在卡片列表中。
