# API Key 申请指南板块开发计划

## 目标
响应用户需求，在个人门户网站中新增一个“技术分享”风格的板块（或独立页面），专门指导其他教师如何申请并获取主流大语言模型（LLM）的 API Key。这个板块旨在降低非技术背景教师使用 AI 工具的门槛，体现用户的技术视野与教育分享精神。

## 实施步骤

### 1. 内容结构设计
我们将梳理并结构化主流大模型的申请流程，确保内容清晰、步骤明确。
涉及的模型（根据用户提供的图片和常见模型补全）：
- **国内模型（推荐教师优先使用）**：
  - 智谱 GLM (ZhipuAI)
  - 深度求索 (DeepSeek)
  - 通义千问 (Alibaba Qwen)
  - 月之暗面 (Moonshot Kimi)
- **国际模型**：
  - Google Gemini
  - OpenAI (ChatGPT)
  - Anthropic (Claude)

**每张卡片/每个区块包含的内容**：
- 模型/服务商名称及 Logo (Icon)。
- 简短的一句话特点介绍（例如：Kimi 擅长长文本，DeepSeek 性价比极高）。
- **一键直达申请链接**。
- 简易的三步申请指南（如：1. 注册登录 -> 2. 进入控制台 -> 3. 创建并复制 API Key）。

### 2. UI/UX 界面设计
为了保持当前网站“文艺科技风”的 Vibe Coder 质感，该板块将采用以下设计：
- **位置安排**：
  - 在 `Home.tsx` 的“工具与创作”和“随笔与动态”之间，新增一个名为 `API 指南 (API Hub)` 的全新 Section。
  - 在顶部导航栏中增加对应的锚点跳转链接：`API 申请`。
- **展示形式**：
  - 采用**手风琴 (Accordion)** 或**精美的网格卡片 (Bento Grid)** 布局。考虑到技术分享的阅读体验，卡片式布局（点击展开详细步骤或直接在卡片上显示简要步骤）最为合适。
  - 风格将延续圆角玻璃拟态、微阴影和柔和的交互动画。

### 3. 代码实现路径
- **新增组件**：在 `src/pages/Home.tsx` 中编写新的 `<section id="api-hub">`。
- **数据定义**：在组件内部或独立文件中定义一个 `apiProviders` 数组，包含上述各大模型的名称、描述、申请链接和步骤文本。
- **样式开发**：利用 Tailwind CSS 和 Framer Motion 实现卡片的悬浮、高亮链接（使用品牌色 `#2A6049`）以及优雅的进入动画。

## 预期效果
- 访问者滚动到该区域时，会看到一个名为“AI 引擎：API Key 申请指南”的板块。
- 页面不仅美观，而且极具实用价值。有兴趣的老师可以直接点击卡片中的按钮，跳转到对应的官方后台快速获取 API Key，从而顺利使用诸如 Write Ascend 等需要配置 API 的教育工具。
